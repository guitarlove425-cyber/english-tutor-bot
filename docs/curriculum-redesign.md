# English Tutor Bot curriculum redesign

## Design principles

The redesigned bot uses a blended classroom model. Beginners receive explicit Burmese-first teaching, controlled practice, and sentence frames. Once learners have enough language, action-oriented scenarios and task-based practice become more prominent. Every activity has one observable outcome, one modality priority, one success check, and one next action.

The core Academy is the structured spine. The Beginner Course is a short bridge for learners who want a compact start. Kids English is a separate child-safe phonics, story, literacy, and project pathway. Practice features are not duplicate copies of the core lesson: each has its own task bank and outcome.

## Non-overlap contract

| Feature | Primary purpose | Content source | Evidence |
|---|---|---|---|
| Beginner Course | Foundation bridge | 18 original everyday lessons | sentence production and short conversations |
| Academy | CEFR-sequenced language system | 60 lessons across six levels, ten per level | lesson mastery plus checkpoint evidence |
| Kids School | Age-graded phonics, literacy, and communication | 36 lessons across six stages | child-safe text/voice practice and projects |
| Quiz | Retrieval and discrimination | level-specific quiz focus bank | validated four-option answer and explanation |
| Coach | Adaptive remediation | weak-skill and learner-goal task bank | one coached action and follow-up |
| Daily Plan | Spaced daily practice | distinct daily task templates | measurable minutes and completion |
| Word Bank | Vocabulary retention | lesson vocabulary plus context tasks | recall, usage, and review interval |
| Pronunciation | Phonological control | sound, stress, rhythm, and connected-speech bank | voice score plus repeat task |
| Live Voice | Interaction and turn-taking | level/track scenario bank | conversation turns and one coaching note |
| Role-play | Goal-oriented cooperation | real-world scenario bank | task completion and appropriate register |
| Diagnostic | Baseline placement | six-skill diagnostic bank | skill profile and next recommendation |
| Projects | Multi-lesson action-oriented outcomes | six level-linked projects with milestone tasks | six-part rubric and readiness |
| Classroom | Teacher-led delivery | current lesson plus phase framework | evidence, mastery, review, remediation |

## Lesson template

Every core lesson should contain: a learner-facing can-do objective; target language; vocabulary; a short Burmese explanation; two English models; one common error; a comprehension check; guided practice; an independent task; a pronunciation/listening option; a review item; and a measurable mastery condition. These are authored as original content and do not copy coursebook text.

## Planned expansion

- Beginner Course: 18 lessons, adding personal information, home and town, shopping quantities, health appointments, transport, work messages, problem solving, and a final integrated task.
- Academy: 10 lessons per CEFR band, adding pronunciation foundations, functional transactions, listening strategies, writing/mediation, digital interaction, and level-specific projects without repeating the same task.
- Kids School: 36 lessons, adding one age-appropriate phonics/literacy/project lesson to each existing stage.
- Projects: 12 milestones, with a preparatory and performance milestone for each level.
- Diagnostics: maintain a six-skill baseline but rotate prompts through a larger original question bank.
- Practice features: add deterministic feature task banks so Quiz, Coach, Daily Plan, Pronunciation, Live Voice, Role-play, and Word Bank use different task contexts even when they refer to the same level.

## Assessment and review

The bot will retain regular low-stakes checks, explicit mastery evidence, remedial loops, and spaced review. A repeated topic may reappear only with a new communicative function, higher complexity, or new modality; it must not be counted as a duplicate lesson merely because the topic name is familiar.
