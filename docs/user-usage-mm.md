# FluentEnglishTutor Bot — User အသုံးပြုနည်း

**Bot:** `@fluent_eng_tutor_bot`

ဤလမ်းညွှန်စာအုပ်သည် မြန်မာအသုံးပြုသူများအတွက် ရေးထားသော User Manual ဖြစ်ပါသည်။ Bot ၏ လမ်းညွှန်ချက်၊ မေးခွန်း၊ အမှားပြင်ပေးချက်နှင့် အသုံးပြုနည်းများကို မြန်မာလိုပေးပါမည်။ သင်လေ့ကျင့်ရမည့် target English စာကြောင်းများ၊ မေးခွန်းများနှင့် speaking အဖြေများကိုတော့ English ဖြင့် ထားရှိပါမည်။

> **အဓိကအကြံပြုချက်:** Bot ကို Chatbot တစ်ခုလို အဖြေတောင်းရုံမဟုတ်ဘဲ ဆရာတစ်ယောက်လို အသုံးပြုပါ။ ဆရာရှင်းပြချက်ကိုဖတ်ပါ၊ ဥပမာကိုနားထောင်ပါ၊ မေးခွန်းကိုဖြေပါ၊ ကိုယ်တိုင် English ဖြင့် ပြော/ရေးပါ၊ ပြီးမှ နောက်အဆင့်ကို ဆက်ပါ။

## ၁။ Bot စတင်အသုံးပြုနည်း

1. Telegram တွင် `@fluent_eng_tutor_bot` ကိုရှာပါ။
2. **Start** ကိုနှိပ်ပါ သို့မဟုတ် `/start` ပို့ပါ။
3. Bot က Burmese-first Main Menu ကို ပြပါမည်။
4. Menu မှ လုပ်ချင်သည့်အရာကို ခလုတ်ဖြင့် ရွေးပါ။ Command များကို မမှတ်မိလည်း အောက်က Telegram ခလုတ်များဖြင့် အသုံးပြုနိုင်ပါသည်။
5. Lesson အတွင်းရောက်ပါက Bot သည် ခလုတ်များအားလုံးကို တစ်ခါတည်း မပြဘဲ လက်ရှိအဆင့်အတွက် လိုအပ်သည့် နောက်ခလုတ်တစ်ခုကိုသာ ပြပါမည်။

အမြဲတမ်း Main Menu သို့ပြန်လိုပါက `/menu` ပို့ပါ။ သင့် Telegram numeric ID ကို သိလိုပါက `/myid` ပို့ပါ။

## ၂။ Main Menu ကို နားလည်ခြင်း

Main Menu တွင် အောက်ပါအပိုင်းများရှိပါသည်။

| ခလုတ် | အသုံးပြုရန် |
|---|---|
| **📚 Learning** | Academy၊ Level၊ Beginner Course နှင့် Daily Plan သို့သွားရန် |
| **🧒 Kids English School** | ကလေးများအတွက် မူလတန်းမှ Young Pro အထိ လေ့လာရန် |
| **👩‍🏫 ဒီနေ့ ဆရာ့ Lesson** | လက်ရှိ teacher-led lesson ကို ဆက်ရန် |
| **🧰 Practice** | Quiz၊ Role-play၊ Voice၊ Diagnostic၊ Project စသည့် လေ့ကျင့်ခန်းများ |
| **📊 Progress** | Skill Report၊ Daily Plan၊ Review နှင့် Certificate ကြည့်ရန် |
| **👤 Profile** | Learning goal၊ အချိန်၊ practice type၊ confidence စသည်ဖြင့် Profile ပြင်ရန် |
| **📘 Beginner Course** | ၁၂ ခန်းပါ အခြေခံ Speaking သင်တန်း |

| **❓ Help** | Command နှင့် အသုံးပြုနည်းများ |

Lesson တက်နေချိန်တွင် Main Menu ခလုတ်များ မပေါ်နိုင်ပါ။ ထိုအချိန်တွင် **🏠 Home** သို့မဟုတ် **🏠 သင်ခန်းစာရပ်ပြီး Home သွားမယ်** ကိုနှိပ်၍ ထွက်ပြီးမှ Main Menu ကို ပြန်အသုံးပြုပါ။

## ၃။ Beginner Speaking Course

Beginner Course သည် English ကို အခြေခံအကျဆုံးမှ စတင်လိုသူများအတွက် ၁၂ ခန်းပါ လမ်းကြောင်းဖြစ်ပါသည်။ Greetings၊ alphabet/sounds၊ be verbs၊ numbers၊ family၊ daily routine၊ questions၊ time၊ food/shopping၊ directions၊ yesterday/tomorrow နှင့် real-life conversation တို့ကို အဆင့်လိုက် လေ့လာနိုင်ပါသည်။

### စတင်နည်း

1. Main Menu မှ **📘 Beginner Course** ကိုနှိပ်ပါ၊ သို့မဟုတ် `/course` ပို့ပါ။
2. **📘 ဒီသင်ခန်းစာ** ဖြင့် လက်ရှိ lesson ကိုဖွင့်ပါ။
3. **👩‍🏫 ဆရာဦးဆောင် Lesson** ကိုရွေးပါ။
4. Bot က တစ်ဆင့်ချင်း သင်ပေးပါမည်။

### Beginner command များ

```text
/course          Beginner Course စရန်
/lesson          လက်ရှိ lesson ကြည့်ရန်
/teacherlesson   ဆရာဦးဆောင်အဆင့်လိုက် Lesson စရန်
/nextlesson      Mastery ရပြီးနောက် နောက် lesson သွားရန်
/progress        Beginner တိုးတက်မှုကြည့်ရန်
/resetcourse     Beginner progress ပြန်စရန်
```

`/resetcourse` သည် လက်ရှိ Beginner progress ကို ပြန်စနိုင်သည့်လုပ်ဆောင်ချက်ဖြစ်သောကြောင့် မသေချာဘဲ မနှိပ်ပါနှင့်။

## ၄။ Premium English Speaking Academy

Academy သည် အခြေခံမှ Pro အထိ လမ်းကြောင်းရှည်ဖြစ်ပါသည်။ Level ၆ ခုနှင့် Lesson ၃၆ ခန်း ပါဝင်ပါသည်။

| Level | CEFR | အခြေအနေ |
|---|---|---|
| Starter | A0 | Free path |
| Elementary | A1 | Free path |
| Pre-Intermediate | A2 | Premium |
| Intermediate | B1 | Premium |
| Upper-Intermediate | B2 | Premium |
| Advanced/Pro | C1+ | Premium |

### Academy စတင်နည်း

1. Main Menu မှ **📚 Learning** ကိုနှိပ်ပါ။
2. **🏫 Speaking Academy** ကိုနှိပ်ပါ၊ သို့မဟုတ် `/academy` ပို့ပါ။
3. Bot က Placement interview/test ဖြင့် သင့်အဆင့်ကို ခန့်မှန်းပါမည်။
4. အကြံပြုထားသော level သို့မဟုတ် Free level မှ စတင်ပါ။
5. **📘 ဒီသင်ခန်းစာ** ဖြင့် လက်ရှိ lesson ကိုဖွင့်ပါ။

### Teacher-led Academy flow

Academy သင်ခန်းစာများသည် အောက်ပါ classroom sequence အတိုင်း သွားပါမည်။

> **Explain → Model → Check → Guided Practice → Independent Use → Assess → Homework → Review**

Bot သည် ဆရာကဲ့သို့ ရှင်းပြပြီး English ဥပမာများပေးပါမည်။ သင်က အဖြေကို စာဖြင့်ပို့နိုင်သလို Voice message ဖြင့်လည်း ပို့နိုင်ပါသည်။ Lesson mastery မရသေးလျှင် Bot က အားနည်းနေသော skill ကို ပြန်လေ့ကျင့်ပေးပြီး နောက် lesson ကို အလွယ်တကူ ကျော်မသွားစေပါ။

### Academy command များ

```text
/academy             Academy စရန် သို့မဟုတ် ပြန်ဆက်ရန်
/levels              Level များနှင့် Premium အခြေအနေကြည့်ရန်
/academylesson       လက်ရှိ Academy lesson ပြန်ကြည့်ရန်
/teacherlesson       Teacher-led phase စရန်
/nextacademylesson   Mastery ရပြီးနောက် နောက် lesson သွားရန်
/academyprogress     Level၊ points၊ streak၊ progress ကြည့်ရန်
/academyreview       ပြီးခဲ့သည့် lesson ပြန်လေ့ကျင့်ရန်
/academyassessment   Checkpoint assessment ဖြေရန်
/academyreset        Academy progress ပြန်စရန်
```

Premium level သို့ ဝင်လိုပါက Bot Admin ထံမှ Manual Premium ဖွင့်ပေးရန် တောင်းပါ။ Admin သည် သင့် Telegram numeric ID နှင့် သက်တမ်းရက်အရေအတွက်ကို အသုံးပြု၍ ဖွင့်ပေးပါမည်။

## ၅။ Lesson အတွင်း ဘယ်လိုအသုံးပြုရမလဲ

Lesson စတင်ချိန်တွင် Bot က သင်ခန်းစာရည်ရွယ်ချက်၊ English model နှင့် လေ့ကျင့်ရမည့်အချက်ကို ပြပါမည်။ ထို့နောက် ခလုတ်တစ်ခုတည်းဖြင့် တစ်ဆင့်ချင်း သွားပါမည်။

| အဆင့် | သင်လုပ်ရမည့်အရာ |
|---|---|
| ရှင်းပြချက် | Burmese explanation ကို ဖတ်ပြီး အဓိပ္ပာယ်နားလည်ပါ |
| ဥပမာ | English model ကို ဖတ်/နားထောင်ပြီး အသံထွက်လိုက်လုပ်ပါ |
| Check | Bot မေးသော မေးခွန်းကို စာဖြင့် သို့မဟုတ် အသံဖြင့် ဖြေပါ |
| Guided | Sentence starter သို့မဟုတ် hint ကိုသုံးပြီး လိုက်လုပ်ပါ |
| Independent | ကိုယ်တိုင် English sentence သို့မဟုတ် voice အဖြေ ပို့ပါ |
| Assess | ဆရာ့အကဲဖြတ်ချက်နှင့် ပြင်ဆင်ရန်အချက်များကို ကြည့်ပါ |
| Homework | သတ်မှတ်ထားသော speaking/writing လေ့ကျင့်ခန်းလုပ်ပါ |
| Review | မမှတ်မိသေးသောအချက်များကို ပြန်လေ့ကျင့်ပါ |

Lesson အတွင်း Bot က မည်သည့်ခလုတ်ကို နှိပ်ရမည်ကို စာသားဖြင့်လည်း ရှင်းပြပေးပါမည်။ ခလုတ်တစ်ခု မပေါ်သေးလျှင် လက်ရှိအဆင့် AI response ပြီးဆုံးသည်အထိ စောင့်ပါ။ ရှင်းပြချက်၊ ဥပမာ၊ Check၊ Guided Practice နှင့် Review အဆင့်များတွင် အသံဖိုင်မလိုအပ်ပါ။ Bot က တကယ်လိုအပ်သည့် Independent Speaking၊ Pronunciation၊ Live Voice သို့မဟုတ် သီးခြား Voice Diagnostic အဆင့်ရောက်မှသာ Voice ပို့ရန် ညွှန်ကြားပါမည်။

## ၆။ Academy Practice tools

Main Menu မှ **🧰 Practice** ကိုနှိပ်၍ အောက်ပါ လေ့ကျင့်ခန်းများကို အသုံးပြုနိုင်ပါသည်။

| Feature | အသုံးပြုပုံ |
|---|---|
| **🧠 Lesson Quiz** | လက်ရှိ lesson အပေါ်မူတည်သည့် A/B/C/D မေးခွန်းဖြေခြင်း |
| **🎭 Role-play** | ခရီးသွားခြင်း၊ အလုပ်၊ နေ့စဉ်ဘဝ စသည့် အခြေအနေများတွင် စကားပြောခြင်း |
| **🗣️ Pronunciation Coach** | Voice ပို့၍ အသံထွက်နှင့် clarity feedback ရယူခြင်း |
| **📖 My Word Bank** | Lesson vocabulary နှင့် spaced repetition review |
| **🎙️ Live Voice** | Multi-turn voice conversation ဖြင့် speaking လေ့ကျင့်ခြင်း |
| **📝 Assessment** | Speaking skill များကို အဆင့်မြင့် စစ်ဆေးခြင်း |
| **🧭 အခြေခံစစ်ဆေးမှု** | Grammar၊ vocabulary၊ reading၊ listening၊ speaking၊ fluency baseline စစ်ခြင်း |
| **🎯 Real-life Project** | လက်တွေ့ project တင်ပြီး rubric ဖြင့် အကဲဖြတ်ခြင်း |
| **🩺 အမှားပြန်သင်ခန်းစာ** | ထပ်ခါထပ်ခါမှားသောအချက်များကို mini-class အဖြစ် ပြန်သင်ခြင်း |
| **🗣️ စကားပြောလှေကား** | Short answer မှ two-minute response အထိ တစ်ဆင့်ချင်း လေ့ကျင့်ခြင်း |

### Quiz ဖြေခြင်း

Quiz မေးခွန်းရောက်လာလျှင် A, B, C, D ခလုတ်ထဲမှ အဖြေတစ်ခုကို ရွေးပါ။ Bot က မှန်/မှားကို Burmese ဖြင့် ရှင်းပြပြီး မှန်ကန်သော English ဥပမာကို ပြပါမည်။ မေးခွန်းအသစ်လိုပါက **🧠 မေးခွန်းအသစ်** ကိုနှိပ်ပါ။

### Voice အသုံးပြုခြင်း

Voice လေ့ကျင့်ခန်းတွင် Bot က အသံလိုအပ်ကြောင်း ပြောသည့်အခါမှ Telegram microphone ကိုနှိပ်ပြီး အဖြေကို English ဖြင့် ပြောကာ ပို့ပါ။ ရှင်းပြချက်၊ model၊ check နှင့် guided practice အဆင့်များအတွက် အသံဖိုင်မပို့ပါနှင့်။ မသိတဲ့ English စကားလုံး သို့မဟုတ် ဝါကျအသံထွက်ကို နားထောင်ချင်လျှင် သင်ခန်းစာထဲက **🔊 မသိတဲ့စာလုံး အသံထွက်နားထောင်မယ်** ခလုတ်ကိုနှိပ်ပြီး စကားလုံးကို စာဖြင့်ပို့ပါ။ Bot က အဲဒီစာလုံးကို အသံဖိုင်အဖြစ် ပြန်ဖတ်ပေးပါမည်။ အသံကို တတ်နိုင်သမျှ တိုတို၊ ရှင်းရှင်းနှင့် ဆူညံသံနည်းသောနေရာမှ ပို့ပါ။ Bot က transcription၊ grammar၊ fluency သို့မဟုတ် pronunciation အပေါ်မူတည်၍ feedback ပြန်ပေးပါမည်။

## ၇။ Learning Coach နှင့် Daily Study Plan
